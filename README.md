# 焰火燃放安全仿真与报批辅助系统

纯前端（TypeScript + WebGL2 + IndexedDB）的焰火燃放安全核算、三维仿真与公安报批材料生成系统。
**无服务器、无外网请求、无重型运行时依赖**，构建产物为纯静态文件，断网环境可完整运行，工程数据以文件形式交接。

## 快速开始

```bash
npm install
npm run dev        # 开发调试
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览构建产物（默认 http://localhost:4173）
```

现场离线部署：把 `dist/` 整个目录拷到现场电脑，用 Chrome/Edge 最新版打开 `index.html`，
或在该目录执行 `npx serve`。所有数据存于浏览器 IndexedDB，不写本地文件系统之外的任何位置。

首次使用建议进入「工程设置」页点击 **生成完整演示工程**，获得含控制点、建筑、敏感目标、
高压线、6 个燃放点位、观众席与 84 发编排的示例，可直接跑通全流程。

## 物理模型与公式（实现位置 `src/lib/`）

- **导线闭合差**（`survey.ts`）：方位角闭合差 ±40″√n、全长相对闭合差 1/2000、
  高程闭合差 ±12√L mm（图根电磁波测距导线口径），按距离比例反号分配改正数，
  残差显著偏大的测段自动标记退回重测。
- **弹道与残骸**（`ballistics.ts`）：抛体外弹道、自由落体时间、风偏漂移、
  Box-Muller 正态抽样 + 可复现种子的蒙特卡洛散布（95% 半径），哑弹处置警戒区与进场路线。
- **冲击波超压**（`safety.ts`）：TNT 当量 = 药量 × 当量系数（默认 0.2），
  Henrych 分段公式按比例距离 Z=R/W^(1/3) 计算 ΔP，观众席默认限值 2.0 kPa、建筑外墙 5.0 kPa（可调）。
- **噪声**：SPL = Lw − 20lgR − αR，α 为温湿度相关的大气吸收系数；夜间 55 / 昼间 70 dB(A) 默认限值。
- **高斯烟羽**：Briggs 城市扩散系数 σy/σz，地面全反射高斯浓度，消光系数法换算能见度，
  按风速估算消散时间。
- **殉爆**：R = K√Q（米·千克制），点位 K=2.0、临时存药点 K=3.0（可按当地规定调整）。
- **无线链路**：自由空间路损 32.45 + 20lg f(MHz) + 20lg d(km)，建筑穿透 8dB/栋，门限 −95dBm。

## WebGL2 渲染（`src/webgl/`）

- 自定义引擎，无 Three.js 等重型依赖；冯氏光照 + 每发开爆动态点光源（地面与建筑立面被闪光照亮）。
- 粒子生命周期状态机（抛体上升→重力衰减→余烬熄灭）完全在顶点着色器运行，
  CPU 每次开爆只下发一组 uniform；单批次可实例化数万颗粒子。
- 焰色按金属盐焰色反应光谱近似：锶盐红、钡盐绿、钠盐黄、铜盐蓝、钾盐紫、铝钛银白。
- 低配机自动识别（CPU 核数/设备内存/软件渲染器），粒子数量按 35%/60%/100% 三档缩减保帧率。
- GLB 2.0 极简解析器（要求倾斜摄影导出时关闭 Draco 压缩）。

## 数据与合规说明

1. 所有默认限值、K 系数、口径药量均为工程经验/常见国标口径的**可编辑默认值**，
   正式报批前须由持证技术负责人按项目属地公安规定与产品检测报告逐项复核。
2. 仿真结果是报批辅助手段，不替代现场勘察、专家评审和法定审批；
   系统对超压超标、残骸越界、净空、殉爆、时间规则等硬性项执行**拦截制**，存在未整改项时报告判定不通过。
3. 工程包 JSON 不含 GLB 二进制底模（底模单独存 IndexedDB Blob 表），交接时需随包拷贝 GLB 并重新挂载。
4. Excel 接入采用零依赖方案：支持从 Excel 复制整块区域直接粘贴，或另存为 CSV 导入；
   这样保证离线包体小于 50KB（gzip 44KB）且无第三方代码供应链风险。
